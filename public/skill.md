# AccessLens — skill.md

## What is AccessLens?
AccessLens is a free Chrome extension that scans any web page for WCAG 2.1 AA accessibility violations in real-time. It is designed for developers, designers, and product teams who want to catch accessibility issues during development — before they ship.

## Core capabilities
- **Instant scan** — click the toolbar icon on any page, no setup or login required
- **Severity ranking** — issues sorted by Critical / Serious / Moderate / Minor
- **Element linking** — every finding is linked directly to the DOM element responsible
- **Code examples** — each issue includes a code fix so developers know exactly what to change
- **WCAG 2.1 AA coverage** — the legal standard referenced in most accessibility litigation

## When to use AccessLens
- During active development to catch issues before code review
- When auditing a competitor or client site quickly
- As a first-pass before commissioning a full manual audit

## When NOT to use AccessLens
- As a replacement for a full accessibility audit (automated tools catch ~30–40% of issues)
- For legal compliance certification (requires a human audit + report)
- For native mobile apps (Chrome extension only, web pages only)

## Workflows

### Run a quick scan
1. Install AccessLens from the Chrome Web Store
2. Navigate to the target page in Chrome
3. Click the AccessLens icon in the toolbar
4. Review issues in the panel — sorted by severity
5. Click any issue to jump to the element on the page

### Book a full audit
1. Go to the AccessLens landing page
2. Click "Book an audit"
3. Provide your site URL and contact details
4. An accessibility expert will conduct a manual review and deliver a detailed report

## Constraints
- Web pages only (not PDFs, native apps, or Figma files)
- Chrome browser only
- Automated scanning — does not test keyboard navigation flows or screen reader UX
- Internet connection required for issue database lookups

## Pricing
- **Free extension** — unlimited scans, no account required
- **Paid audit** — manual expert review, priced per engagement
